# Sujal Santosh Dharne Portfolio

A cinematic personal portfolio for Sujal Santosh Dharne, an Aerospace and Mechanical Engineering student at the University at Buffalo.

**Live:** [sujal712.github.io/sujal_portfolio](https://sujal712.github.io/sujal_portfolio) | **GitHub:** [sujal712/sujal_portfolio](https://github.com/sujal712/sujal_portfolio)

## Stack

| Layer      | Technology                                    |
| ---------- | --------------------------------------------- |
| Framework  | Next.js 16.2                                  |
| Animations | GSAP 3 + Three.js                             |
| Styling    | CSS Modules + Tailwind v4 tokens              |
| Icons      | react-icons                                   |
| Fonts      | Geist, Baloo 2, Dancing Script via next/font  |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

To build for production:

```bash
npm run build
npm start
```

## Content

Resume-backed portfolio content lives in `data/profile.json`.

Site copy for the hero, interstitial, and footer lives in `data/content.json`.

The canonical site URL lives in `lib/siteConfig.js`.
